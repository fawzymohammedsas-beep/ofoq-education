# أُفُق التعليمية — OFOQ

واجهة تعليمية عربية RTL بتصميم أسود وأزرق كهربائي، مع الشعار وصورة معلّم المنصة. تشمل لوحة الطالب، أقسام الكورسات والمحاضرات والملفات والامتحانات، ولوحة تحكم المالك.

## تشغيل المعاينة
1. فك ضغط الملف.
2. افتح `index.html` أو شغّل مجلد المشروع باستخدام VS Code Live Server.
3. عند عدم إعداد Firebase، اضغط «استكشف النسخة التجريبية». بيانات المعاينة تُحفظ في نفس المتصفح فقط؛ لا تستخدمها لحسابات حقيقية.

## تفعيل المنصة الحقيقية (مطلوب قبل إرسال الرابط للطلاب)

### 1) أنشئ مشروع Firebase
- افتح https://console.firebase.google.com/ وأنشئ مشروعًا.
- من Project settings أضف تطبيق Web وانسخ إعداداته إلى `firebase-config.js` بدل القيم `PASTE_...`.
- من Authentication > Sign-in method فعّل Google.
- من Authentication > Settings > Authorized domains أضف نطاق موقعك بعد النشر.
- أنشئ Firestore Database وفعّل Firebase Storage.

### 2) انشر قواعد الأمان
ثبّت Firebase CLI على جهازك، ثم من مجلد المشروع نفّذ: `firebase login`، ثم اربط المشروع: `firebase use --add`، وبعدها `firebase deploy --only firestore:rules,storage`. لا تستخدم قواعد مفتوحة للعامة.

### 3) انشر الموقع
بعد إعداد `.firebaserc` أو اختيار مشروعك باستخدام `firebase use --add` نفّذ `firebase deploy --only hosting`. يمكن أيضًا رفع ملفات الواجهة إلى استضافة ثابتة، مع إضافة نطاق الاستضافة إلى Authorized domains.

## ما الذي أصبح مرتبطًا بالكود؟
- زر Google يستعمل Firebase Authentication عند إضافة الإعدادات الصحيحة.
- المحتوى يقرأ من Firestore؛ المالك يرى المسودات، والطلاب المسجلون يرون المنشور فقط.
- المالك يستطيع إضافة المحتوى وتعديله وحذفه من خلال صلاحيات Firestore.
- ملفات PDF ترفع إلى Firebase Storage عند تسجيل دخول المالك، ثم يظهر رابطها للطلاب المسجلين.
- قواعد Firestore وStorage تمنع الطلاب من الكتابة، وتقيّد الكتابة بحساب Google الذي بريده `fawzymohammedsas@gmail.com`.

## حدود النسخة الحالية
- **لا يمكن تشغيل تسجيل Google أو قاعدة بيانات مشتركة قبل وضع بيانات مشروع Firebase الفعلية ونشر القواعد.** لا يمكن إنشاء مشروع Firebase أو تفعيل خدماته نيابةً عنك دون دخولك إلى حسابك.
- قسم الامتحان الحالي نموذج لسؤال اختيار من متعدد واحد، وليس بعد نظام امتحانات متقدم متعدد الأسئلة أو مراقبة محاولات وشهادات إنتاجية.
- لوحة إدارة المشتركين والحظر/التفعيل التفصيلي، والتقارير والشهادات الآلية، تحتاج مراحل تطوير إضافية.
- رابط تليجرام المرتبط برقم الهاتف قد لا يعمل دائمًا؛ استبدله برابط `t.me/username` الحقيقي عند توفره.
- لا تضع مفاتيح خدمة Firebase Admin أو service-account في ملفات الويب. قواعد الأمان هي أساس الحماية، وليس إخفاء زر الإدارة.
